Vue 3 transform 与 codegen 源码解析：AST 如何生成 render 函数

发表于2026|更新于2026|Vue框架及周边库
|字数总计:1.5k|阅读时长:6分钟

源码说明：本文分析的源码基于 vue@3.5.21，对应官方仓库为 vuejs/core，本文所在学习仓库为 XY0987/vue_ori_learning。

前言：parse 得到的是模板 AST，但它还不能直接生成高效 render 函数。transform 阶段会改写 AST、处理指令、收集 helper，并生成 codegenNode。codegen 阶段再把这些节点输出为 render 函数字符串。

transform 做什么

transform 的入口是：

export function transform(root: RootNode, options: TransformOptions): void {
  const context = createTransformContext(root, options)
  // 深度遍历 AST，并按顺序执行 nodeTransforms/directiveTransforms。
  traverseNode(root, context)
  if (options.hoistStatic) {
    cacheStatic(root, context)
  }
  if (!options.ssr) {
    // 为 root 生成最终 codegenNode，codegen 阶段会从这里开始输出 render 表达式。
    createRootCodegen(root, context)
  }
  // finalize meta information
  root.helpers = new Set([...context.helpers.keys()])
  root.components = [...context.components]
  root.directives = [...context.directives]
  root.imports = context.imports
  root.hoists = context.hoists
  root.temps = context.temps
  root.cached = context.cached
  root.transformed = true
}

transform 做的事情包括：

  • 遍历 AST
  • 执行节点转换插件
  • 执行指令转换插件
  • 收集 runtime helpers
  • 收集组件和指令资源
  • 静态提升
  • 生成 root.codegenNode

traverseNode：转换插件如何执行

traverseNode 是 AST 遍历核心：

export function traverseNode(
  node: RootNode | TemplateChildNode,
  context: TransformContext,
): void {
  context.currentNode = node
  // 先执行进入阶段的 nodeTransforms；它们可以返回退出函数，在子节点遍历完成后倒序执行。
  const { nodeTransforms } = context
  const exitFns = []
  for (let i = 0; i < nodeTransforms.length; i++) {
    const onExit = nodeTransforms[i](node, context)
    if (onExit) {
      if (isArray(onExit)) {
        exitFns.push(...onExit)
      } else {
        exitFns.push(onExit)
      }
    }
    if (!context.currentNode) {
      // node was removed
      return
    } else {
      // node may have been replaced
      node = context.currentNode
    }
  }

  switch (node.type) {
    case NodeTypes.COMMENT:
      if (!context.ssr) {
        context.helper(CREATE_COMMENT)
      }
      break
    case NodeTypes.INTERPOLATION:
      if (!context.ssr) {
        context.helper(TO_DISPLAY_STRING)
      }
      break
    case NodeTypes.IF:
      for (let i = 0; i < node.branches.length; i++) {
        traverseNode(node.branches[i], context)
      }
      break
    case NodeTypes.IF_BRANCH:
    case NodeTypes.FOR:
    case NodeTypes.ELEMENT:
    case NodeTypes.ROOT:
      traverseChildren(node, context)
      break
  }

  // 退出阶段倒序执行，常用于先让子节点完成转换，再基于子节点结果生成当前节点的 codegenNode。
  context.currentNode = node
  let i = exitFns.length
  while (i--) {
    exitFns[i]()
  }
}

这里的进入/退出模型很重要。

进入阶段可以处理结构，比如 v-if、v-for 替换当前节点。退出阶段可以等子节点处理完后，再根据子节点结果生成当前节点的 codegenNode。

这类转换会把普通元素节点转换成 IF、FOR 等更适合 codegen 的节点结构。

codegen 做什么

codegen 的入口是 generate：

export function generate(
  ast: RootNode,
  options: CodegenOptions & {
    onContextCreated?: (context: CodegenContext) => void
  } = {},
): CodegenResult {
  // codegen 入口：基于 transform 后的 AST 输出 render/ssrRender 函数字符串。
  const context = createCodegenContext(ast, options)
  if (options.onContextCreated) options.onContextCreated(context)
  const {
    mode,
    push,
    prefixIdentifiers,
    indent,
    deindent,
    newline,
    scopeId,
    ssr,
  } = context

它做的主要事情是：

  1. 创建 codegen context。
  2. 生成 preamble，比如 helper 引入。
  3. 生成 render 函数签名。
  4. 输出资源解析代码。
  5. 输出 VNode 树表达式。
  6. 返回 { code, ast, map }。

小结

  1. transform 遍历 AST 并执行插件，把模板 AST 改造成适合 codegen 的形态。
  2. TransformContext 负责收集 helpers、components、directives、hoists 等元信息。
  3. traverseNode 有进入和退出两个阶段，退出阶段常用于生成当前节点的 codegenNode。
  4. generate 把 transform 后的 AST 输出成 render 函数字符串。
  5. genNode 是 codegen 的递归分发器。
  6. genVNodeCall 会生成运行时创建 VNode 的调用代码。
