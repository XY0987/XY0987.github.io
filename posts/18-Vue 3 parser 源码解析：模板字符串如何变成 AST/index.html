Vue 3 parser 源码解析：模板字符串如何变成 AST

发表于2026|更新于2026|Vue框架及周边库
|字数总计:986|阅读时长:4分钟

源码说明：本文分析的源码基于 vue@3.5.21，对应官方仓库为 vuejs/core，本文所在学习仓库为 XY0987/vue_ori_learning。

前言：编译器第一步是 parse。它的任务是把模板字符串切成 token，再组装成模板 AST。AST 是后续 transform 和 codegen 的基础。

先给结论

parser 的核心流程是：

baseParse(template)
  │
  ├─ reset parser state
  ├─ merge parser options
  ├─ create root node
  ├─ tokenizer.parse(input)
  │    ├─ ontext
  │    ├─ onopentagname
  │    ├─ onattribname / ondirname
  │    ├─ oninterpolation
  │    └─ onclosetag
  ├─ condenseWhitespace
  └─ return RootNode

parser 状态

parser.ts 中维护了一组解析状态：

// parser state
// 这些状态由 tokenizer 回调逐步维护：当前输入、当前打开标签、当前属性、标签栈等。
let currentInput = ''
let currentOpenTag: ElementNode | null = null
let currentProp: AttributeNode | DirectiveNode | null = null
let currentAttrValue = ''
let currentAttrStartIndex = -1
let currentAttrEndIndex = -1
let inPre = 0
let inVPre = false
let currentVPreBoundary: ElementNode | null = null
const stack: ElementNode[] = []

其中 stack 很重要，它表示当前还没有闭合的元素栈。新节点会挂到栈顶元素下面；如果栈为空，则挂到根节点下面。

tokenizer 和 parser 的关系

parser 不是自己逐字符手写所有分支，而是通过 Tokenizer 触发回调：

// tokenizer 负责把模板字符流切成 token；parser 通过这些回调把 token 组装成 AST 节点。
const tokenizer = new Tokenizer(stack, {
  onerr: emitError,

  ontext(start, end) {
    onText(getSlice(start, end), start, end)
  },

  ontextentity(char, start, end) {
    onText(char, start, end)
  },

  oninterpolation(start, end) {
    if (inVPre) {
      return onText(getSlice(start, end), start, end)
    }
    let innerStart = start + tokenizer.delimiterOpen.length
    let innerEnd = end - tokenizer.delimiterClose.length
    while (isWhitespace(currentInput.charCodeAt(innerStart))) {
      innerStart++
    }
    while (isWhitespace(currentInput.charCodeAt(innerEnd - 1))) {
      innerEnd--
    }
    let exp = getSlice(innerStart, innerEnd)

比如遇到文本会触发 ontext，遇到插值会触发 oninterpolation，遇到开始标签会触发 onopentagname。

元素如何入树

开始标签结束时，会调用 endOpenTag：

function endOpenTag(end: number) {
  // 开始标签结束时，把 currentOpenTag 加入当前父节点，并根据是否自闭合/void 决定是否入栈。
  if (tokenizer.inSFCRoot) {
    // in SFC mode, generate locations for root-level tags' inner content.
    currentOpenTag!.innerLoc = getLoc(end + 1, end + 1)
  }
  addNode(currentOpenTag!)
  const { tag, ns } = currentOpenTag!
  if (ns === Namespaces.HTML && currentOptions.isPreTag(tag)) {
    inPre++
  }
  if (currentOptions.isVoidTag(tag)) {
    onCloseTag(currentOpenTag!, end)
  } else {
    stack.unshift(currentOpenTag!)
    if (ns === Namespaces.SVG || ns === Namespaces.MATH_ML) {
      tokenizer.inXML = true
    }
  }
  currentOpenTag = null
}

这里做了两件事：

  1. 把当前元素节点加入父节点 children。
  2. 如果不是 void 标签，就把它放入 stack，后续子节点会挂到它下面。

addNode 很简单：

function addNode(node: TemplateChildNode) {
  // 当前有打开的元素时挂到栈顶元素，否则挂到 root.children。
  ;(stack[0] || currentRoot).children.push(node)
}

文本节点如何处理

文本节点会走 onText：

function onText(content: string, start: number, end: number) {
  // 文本节点会被加入当前栈顶元素；相邻文本会合并，减少 AST 节点数量。
  if (__BROWSER__) {
    const tag = stack[0] && stack[0].tag
    if (tag !== 'script' && tag !== 'style' && content.includes('&')) {
      content = currentOptions.decodeEntities!(content, false)
    }
  }
  const parent = stack[0] || currentRoot
  const lastNode = parent.children[parent.children.length - 1]
  if (lastNode && lastNode.type === NodeTypes.TEXT) {
    // merge
    lastNode.content += content
    setLocEnd(lastNode.loc, end)
  } else {
    parent.children.push({
      type: NodeTypes.TEXT,
      content,
      loc: getLoc(start, end),
    })
  }
}

相邻文本会合并，避免 AST 里产生过多碎片节点。

baseParse 入口

最终入口是 baseParse：

export function baseParse(input: string, options?: ParserOptions): RootNode {
  // parse 入口：重置全局解析状态，合并解析选项，然后驱动 tokenizer 扫描模板。
  reset()
  currentInput = input
  currentOptions = extend({}, defaultParserOptions)

  if (options) {
    let key: keyof ParserOptions
    for (key in options) {
      if (options[key] != null) {
        // @ts-expect-error
        currentOptions[key] = options[key]
      }
    }
  }

  const root = (currentRoot = createRoot([], input))
  // tokenizer.parse 会同步触发上面的各种回调，逐步填充 root.children。
  tokenizer.parse(currentInput)
  root.loc = getLoc(0, input.length)
  // 解析完成后统一压缩空白节点，得到最终 RootNode。
  root.children = condenseWhitespace(root.children)
  currentRoot = null
  return root
}

baseParse 输出的是 RootNode，后续 transform 会继续处理这个 AST。

小结

  1. parser 通过 tokenizer 回调构建 AST。
  2. stack 用来维护当前元素父子关系。
  3. endOpenTag 决定元素是否入栈。
  4. onText 会合并相邻文本节点。
  5. baseParse 最终返回 RootNode，并进行空白压缩。
